# Поддерживаемые конфигурации и выбор пакета

Для выпуска от **02.11.2026** сохранён список поддерживаемых конфигураций предыдущего выпуска.

| Вариант | Поддерживаемые конфигурации |
|---|---|
| EasyBusyChat | BAS Малий бізнес 1.6; BAS Малий бізнес 2.0 |
| EasyBusyChat 8.3.19 | BAS Малий бізнес 1.6 / 2.0, с «Контакт-центром»; платформа 1С/BAF 8.3.19; обязательный комплект CFE + EPF БСП |
| EasyBusyChat Universal | BAS Малий бізнес 1.6; BAS Малий бізнес 2.0; BAS Управління торгівлею 3.5; BAS Комплексне управління підприємством 3.5; BAS ERP 2.5 |

## Выбор по версии платформы

**Если в BAS Малий бізнес 1.6 / 2.0 установлена платформа 1С/BAF 8.3.19, используйте комплект `EasyBusyChat_8.3.19_v0.10.4.cfe` + `EasyBusyChatScheduler8319.epf`.** Обработка БСП входит в поставку этого варианта и обеспечивает вызов регламентных операций по расписанию. [Инструкция БСП](scheduler-8319_ru.md).

Для более новой платформы выбирайте основное расширение для BAS Малий бізнес или Universal для других конфигураций из таблицы. Альтернативные CFE одновременно не устанавливайте.

| Компонент | Требование |
|---|---|
| Платформа 1С/BAF | 8.3.19.1529 или новее |
| БСП | 3.1 или новее |
| Режим совместимости EasyBusyChat / варианта 8.3.19 | 8.3.17 |
| Режим совместимости Universal | 8.3.14 |
| Веб-плагин | Windows x86/x64, тонкий или толстый клиент |
| Компонент веб-плагина | **[Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section)** на компьютере пользователя |

Версия платформы и режим совместимости — разные характеристики. Файлы поставки собраны платформой **8.3.23.2299**. В веб-клиенте чат открывается по ссылке в браузере. Веб-окно Windows-компоненты предназначено для клиента Windows.

Перед обновлением проверьте копию своей базы. Сведения о выполненных проверках приведены в [примечаниях к выпуску (на украинском)](../releases/2026-11-02/RELEASE_NOTES_uk.md).
