# Easy Busy Chat: краткая настройка

Выпуск от **02.11.2026**: МБ — **0.10.5**, 8.3.19 и Universal — **0.10.4**. Для **BAS Малий бізнес 1.6 / 2.0 с «Контакт-центром» на платформе 1С/BAF 8.3.19** устанавливайте **CFE 8.3.19 и EasyBusyChatScheduler8319.epf**; на более новой платформе выберите основное или Universal-расширение в соответствии с конфигурацией.

Скачайте ZIP нужного варианта из [таблицы на главной странице](../README_ru.md#downloads) и распакуйте его. В архиве есть CFE, украинская инструкция и контрольные суммы; для 8.3.19 также включены EPF и инструкция БСП. При необходимости CFE и EPF можно скачать отдельно.

1. **Подготовьте базу.** Сделайте резервную копию. Проверьте установку и обновление в тестовой копии под администратором. [Выберите вариант](../README_ru.md#downloads); не устанавливайте альтернативные CFE вместе.
2. **Установите WebView2.** Для веб-плагина на каждом рабочем месте Windows необходим **Microsoft Edge WebView2 Runtime**: [официальная загрузка](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section). Перезапустите клиент BAS/BAF после установки.
3. **Подключите CFE.** Откройте «Функции для технического специалиста» → «Управление расширениями конфигурации». Для новой установки добавьте файл, для обновления обновите существующее расширение. Сохраняйте текущий вариант поставки. Не удаляйте расширение для обновления: это может повлиять на его данные. Проверьте параметры безопасности по [полной инструкции](instruction_ru.md#installation), перезапустите клиент.
4. **Подключите сервис.** Откройте Easy-Busy Chats → Администрирование → Настройки. Включите интеграцию, укажите адрес API и свой токен, нажмите «Обновить идентификаторы». Проверьте компанию, учётные записи и пользователя EBC. Храните токен только в настройках базы.
5. **Настройте работу.** Назначьте роли, выберите типы объектов для привязки чатов, сохраните настройки и повторно откройте формы. Загрузите список чатов и проверьте открытие веб-чата.
6. **Для CFE 8.3.19 подключите БСП.** Зарегистрируйте [дополнительную обработку и три расписания](scheduler-8319_ru.md). Начальные интервалы: чаты — **каждую минуту**, справочники — **каждые 15 минут**, ротация журнала — **ежедневно в 03:00** по времени базы. Проверьте ручные запуски и следующее выполнение по расписанию.

После обновления проверьте сохранность связей и настроек. Первоначальная миграция старых связей выполняется порциями и может занять больше времени на большой базе. Тестовую отправку выполняйте только в согласованный тестовый чат.

Если веб-чат не открывается, проверьте Windows-клиент, WebView2 Runtime, разрешения внешней компоненты и журнал регистрации. Если синхронизация не работает — адрес API, токен, HTTPS-доступ и журнал EBC.
