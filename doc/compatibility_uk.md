# Підтримувані конфігурації та вибір пакета

Для випуску від **02.11.2026** збережено перелік підтримуваних конфігурацій попереднього випуску.

| Варіант | Підтримувані конфігурації |
|---|---|
| EasyBusyChat | BAS Малий бізнес 1.6; BAS Малий бізнес 2.0 |
| EasyBusyChat 8.3.19 | BAS Малий бізнес 1.6 / 2.0, з «Контакт-центром»; платформа 1С/BAF 8.3.19; обов’язковий комплект CFE + EPF БСП |
| EasyBusyChat Universal | BAS Малий бізнес 1.6; BAS Малий бізнес 2.0; BAS Управління торгівлею 3.5; BAS Комплексне управління підприємством 3.5; BAS ERP 2.5 |

## Вибір за версією платформи

**Якщо у BAS Малий бізнес 1.6 / 2.0 встановлена платформа 1С/BAF 8.3.19, використовуйте комплект `EasyBusyChat_8.3.19_v0.10.4.cfe` + `EasyBusyChatScheduler8319.epf`.** Обробка БСП входить до поставки цього варіанта та забезпечує виклик регламентних операцій за розкладом. [Інструкція БСП](scheduler-8319_uk.md).

Для новішої платформи обирайте основне розширення для BAS Малий бізнес або Universal для інших конфігурацій із таблиці. Альтернативні CFE одночасно не встановлюйте.

| Компонент | Вимога |
|---|---|
| Платформа 1С/BAF | 8.3.19.1529 або новіша |
| БСП | 3.1 або новіша |
| Режим сумісності EasyBusyChat / варіанта 8.3.19 | 8.3.17 |
| Режим сумісності Universal | 8.3.14 |
| Вебплагін | Windows x86/x64, тонкий або товстий клієнт |
| Компонент вебплагіна | **[Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section)** на комп’ютері користувача |

Версія платформи та режим сумісності — різні характеристики. Файли поставки зібрано платформою **8.3.23.2299**. У вебклієнті чат відкривається за посиланням у браузері. Вебвікно Windows-компоненти призначене для клієнта Windows.

Перед оновленням перевірте копію своєї бази. Відомості про виконані перевірки наведено у [примітках до випуску](../releases/2026-11-02/RELEASE_NOTES_uk.md).
