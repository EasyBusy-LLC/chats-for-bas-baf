# Easy Busy Chat: коротке налаштування

Випуск від **02.11.2026**: МБ — **0.10.5**, 8.3.19 та Universal — **0.10.4**. Для **BAS Малий бізнес 1.6 / 2.0 з «Контакт-центром» на платформі 1С/BAF 8.3.19** установлюйте **CFE 8.3.19 та EasyBusyChatScheduler8319.epf**; на новішій платформі оберіть основне або Universal-розширення відповідно до конфігурації.

Завантажте ZIP потрібного варіанта з [таблиці на головній](../README.md#завантажити-та-обрати-варіант) та розпакуйте його. В архіві є CFE, українська інструкція й контрольні суми; для 8.3.19 також включені EPF та інструкція БСП. За потреби CFE і EPF можна завантажити окремо.

1. **Підготуйте базу.** Зробіть резервну копію. Перевірте встановлення й оновлення в тестовій копії під адміністратором. [Оберіть варіант](../README.md#завантажити-та-обрати-варіант); не встановлюйте альтернативні CFE разом.
2. **Установіть WebView2.** Для вебплагіна на кожному робочому місці Windows потрібен **Microsoft Edge WebView2 Runtime**: [офіційне завантаження](https://developer.microsoft.com/en-us/microsoft-edge/webview2/#download-section). Перезапустіть клієнт BAS/BAF після встановлення.
3. **Підключіть CFE.** Відкрийте «Функції для технічного спеціаліста» → «Управління розширеннями конфігурації». Для нової установки додайте файл, для оновлення використайте оновлення наявного розширення. Зберігайте поточний варіант поставки. Не видаляйте розширення як спосіб оновлення: це може вплинути на його дані. Перевірте параметри безпеки за [повною інструкцією](instruction_uk.md#installation), перезапустіть клієнт.
4. **Підключіть сервіс.** Відкрийте Easy-Busy Chats → Адміністрування → Налаштування. Увімкніть інтеграцію, укажіть адресу API та свій токен, натисніть «Оновити ідентифікатори». Перевірте компанію, облікові записи та користувача EBC. Зберігайте токен лише в налаштуваннях бази.
5. **Налаштуйте роботу.** Призначте ролі, оберіть типи об’єктів для прив’язки чатів, збережіть налаштування та повторно відкрийте форми. Завантажте список чатів і перевірте відкриття вебчату.
6. **Для CFE 8.3.19 підключіть БСП.** Зареєструйте [додаткову обробку та три розклади](scheduler-8319_uk.md). Початкові інтервали: чати — **щохвилини**, довідники — **кожні 15 хвилин**, ротація журналу — **щодня о 03:00** за часом бази. Перевірте ручні запуски й наступне виконання за розкладом.

Після оновлення перевірте збереження зв’язків і налаштувань. Початкова міграція старих зв’язків виконується порціями та може тривати довше на великій базі. Тест надсилання виконуйте лише в погоджений тестовий чат.

Якщо вебчат не відкривається, перевірте Windows-клієнт, WebView2 Runtime, дозволи зовнішньої компоненти та журнал реєстрації. Якщо синхронізація не працює — адресу API, токен, HTTPS-доступ і журнал EBC.
